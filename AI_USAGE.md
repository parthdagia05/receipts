# AI usage

ChatGPT and Claude (through Claude Code) were the only AI tools used, and they were used heavily.

Claude Code sessions wrote most of the code, tests and documentation: the reputation engine, the wallet-review backend, the frontend, the Arkiv module and the specs under `docs/specs/`. Three merge commits carry the `Co-Authored-By: Claude` trailer, and later sessions did the integration QA, the production deployment and the Arkiv publication, each working to the owner's written brief.

The humans set the scope, reviewed and merged every branch, held every key, and approved each deployment and transaction. No AI deployed a contract or sent a transaction on its own, and the code is not audited.
